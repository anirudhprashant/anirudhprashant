## Open source

### [huntline](https://github.com/anirudhprashant/huntline)

A job scout that respects your time. It reads about 100,000 postings a day from 1,100 employer career pages and keeps the few that fit. Employers are checked against the UK, Dutch and Canadian government sponsor lists. Each match gets a tailored resume, a cover letter and an email draft. It never sends anything without you.

Python · MIT · runs on your laptop

### [barestack-app](https://github.com/anirudhprashant/barestack-app)

The back office for agencies and freelancers. CRM, deal pipeline, projects, time tracking, invoicing and expenses in one app. Self-hosted, no seat limits, no per-user pricing. [Try the live demo](https://demo.barestack.org). No sign-up.

React · TypeScript · PocketBase · AGPL-3.0

### [agent-vitals](https://github.com/anirudhprashant/agent-vitals)

An MCP server that tells your AI agent what is actually running on your machine. Cron, systemd, MCP servers, skills. It stops the agent saying "your crontab is fine" when it isn't. 20 CLI commands, 13 MCP tools, 300+ tests. [Docs](https://anirudhprashant.github.io/agent-vitals/).

Python · GPL v3 · no daemon, no cloud, read-only

### [tuxspeak](https://github.com/anirudhprashant/tuxspeak)

Dictation for Linux. Press Alt + Space, speak, press it again. Whisper transcribes, Gemini tidies it, and clean text types at your cursor in any app. Runs on free API tiers. [Site](https://tuxspeak.barestack.org).

C · Shell · GPL 3.0 · X11 and Wayland
